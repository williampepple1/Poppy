Poppy GitHub ↗

The API client
that stays yours.

Poppy is a native, ultra-fast, local-first API client & test runner built with C++20 and Qt 6. All your collections and environments live on your machine — no cloud, no accounts, no lock-in. Inspired by Bruno.

↓ Download for Windows ↓ Download for Linux All releases ↗

Latest · Windows x64 & Linux x64

Everything you need. Nothing extra.

Bruno-compatible Collections

Import and use .bru files directly. Your data stays in plain text on disk.

Multi-tab Workspace

Work across multiple requests simultaneously with a familiar tabbed interface.

Pre & Post Scripts

Run JavaScript snippets before and after requests to dynamically set variables or assert values.

Declarative Assertions

Define pass/fail conditions inline. Run them as a full collection test suite.

GraphQL Support

First-class GraphQL editor with introspection, variable interpolation, and syntax highlighting.

Auth: AWS, OAuth2, mTLS

AWS SigV4, OAuth 2.0, Digest, NTLM, and mutual TLS — all built in.

Cookie Manager

Inspect, edit, and persist cookies across sessions with a dedicated manager dialog.

Request History

Every executed request is automatically logged with status, latency, and full response.

Code Generators

Export any request as cURL, Python, JavaScript, Go, Rust, C#, Java, PHP, or Ruby.

OpenAPI 3.0 Export

Generate a full OpenAPI spec from your collection in one click.

Variable Resolution

Environment, collection, and global variables with {{mustache}} syntax.

Quick Open Palette

Navigate your entire workspace instantly with a fuzzy-search command palette.
